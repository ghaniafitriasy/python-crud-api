# python-crud-api

Python REST API sederhana (health, list, create, delete message) dengan pipeline CI/CD menggunakan Jenkins, GitHub, Docker, dan ngrok.

## Endpoint

- `GET /health`
- `GET /messages`
- `POST /messages` (body JSON: `{"message": "teks"}`)
- `DELETE /messages?index=0`
